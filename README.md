# Dear Layla — 一封会下雨的信

鼠标（或手指）靠近文字，字会慢慢变清晰；偶尔有雨滴落下，泛起水波。

在线预览：GitHub Pages 部署后自动生效（见下方步骤）。

## 本地预览

直接双击 `index.html` 即可在浏览器打开（无需服务器）。

## 部署到 GitHub Pages

1. 新建一个 GitHub 仓库（公开）。
2. 把本文件夹里的全部文件上传到仓库根目录：
   - `index.html`
   - `background.jpg`
   - `font.ttf`
   - `.nojekyll`
3. 仓库设置 → **Pages** → Source 选 `main` 分支 / `(root)` → Save。
4. 等 1~2 分钟，访问 `https://<用户名>.github.io/<仓库名>/` 即可。

> 注意：四个文件都不可缺少，且必须与 `index.html` 在同一目录。
